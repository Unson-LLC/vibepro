## story-vibepro-test-tmpdir-fixture-cleanup - テストスイートが$TMPDIRに残すmkdtemp fixtureのクリーンアップ機構

- Status: PR未作成（gate evidence記録中）

### Change Summary

テストスイートの scratch TMPDIR 隔離により、fixtureリークが原因のENOSPC障害を止める。`test/support/scratch-tmpdir.js` を import した全プロセス(テストヘルパー・src本体・spawnした子プロセス)の `mkdtemp(os.tmpdir())` 呼び出しを、per-process の `vibepro-scratch-*` root配下へリダイレクトし、プロセス正常終了時に削除する。SIGKILL等でexitフックが走らない場合に備え、24時間以上前の `vibepro-scratch-*` 残骸をヘルパーimport時に自己回復として掃除する。

### Compatibility

なし

### User Action

不要。24時間以上経過した `vibepro-scratch-*` の残骸は次回ヘルパーimport時に自動掃除される。任意対応として、per-userの `$TMPDIR` に残っているレガシーな `vibepro-*` / `story-vibepro-*` fixtureの手動一括削除を行ってもよい(必須ではない)。

### Rollback

`test/support/scratch-tmpdir.js` と、それをimportしている行を削除すれば元に戻る。永続化された状態は持たない。

### Observability

`$TMPDIR` 配下のfixture件数で監視できる。回帰は `test/scratch-tmpdir-conformance.test.js` が検知して失敗する。
