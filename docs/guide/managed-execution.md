# Managed Execution

Managed execution and its `execute` commands were part of an earlier VibePro workflow. This page remains at its old URL for link stability; the managed execution controller and progress DAG are retired from the current minimal core.

Use ordinary repository and pull-request workflows together with the [Control Loop](/guide/control-loop). Consult the [Feature Map](/guide/feature-map) for the current command surface. VibePro records evidence for review; it does not orchestrate an agent run or grant merge authority.
