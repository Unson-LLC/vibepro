# Monthly Gate-Tuning Ritual

This URL is retained for older links. Gate DAG tuning, gate-outcome ROI ledgers, and `execute merge` belonged to a previous VibePro workflow and are not current features of the minimal core.

Do not use the commands or artifacts from the historical version of this page for a new project. The current product records Story, Spec, verification, lightweight review, and PR-summary evidence, then hands the change to the repository's normal GitHub review and merge process.
